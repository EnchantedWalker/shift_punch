# Shift Punch

A phone-friendly time clock: clock in and out, log meal breaks, and see a timesheet with daily hours, breaks and pay.

The app is a single page, `index.html`. The live version is published at https://claude.ai/artifact/Cr1qd2bbdHpXkRfPUhbvyK, where each signed-in person's hours are saved to their own Claude account. Opened anywhere else, it saves hours in that browser only.
